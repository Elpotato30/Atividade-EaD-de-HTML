# Atividade-EaD-de-HTML

Meu Perfil Acadêmico

Atividade prática de HTML e CSS da 1ª fase de Análise e Desenvolvimento de Sistemas.

Sobre a página

A página apresenta meu perfil acadêmico, minha formação, meus interesses acadêmicos e meus objetivos na área de tecnologia.

Explicação do código

1. Como você montou a estrutura básica do arquivo index.html?

Montei o arquivo utilizando a estrutura básica de um documento HTML, com <!DOCTYPE html>, <html>, <head> e <body>. O <!DOCTYPE html> informa que o documento utiliza HTML5, o <html> contém toda a página, o <head> reúne as configurações e o <body> contém o conteúdo que aparece no navegador.

2. O que você colocou dentro do <head> e qual é a função de cada elemento utilizado?

Dentro do <head> coloquei o charset="UTF-8", o viewport, o <title> e a tag <style>. O charset permite a exibição correta de acentos, o viewport ajuda a adaptar a página a diferentes telas, o title define o nome exibido na aba do navegador e o style contém as regras de CSS da página.

3. Como você utilizou as duas <div> para separar e organizar os conteúdos da página?

Utilizei duas <div> para separar os conteúdos em diferentes partes da página. A primeira possui a classe perfil e apresenta minhas informações e interesses acadêmicos, enquanto a segunda possui a classe objetivos e apresenta meus objetivos em tecnologia.

4. Como você aplicou o CSS dentro da tag <style>?

Usando seletores para formatar os elementos. Um exemplo presente no código é o seletor h1, onde utilizei a propriedade color com o valor hexadecimal #00A19B para deixar o título principal em tom mais turquesa.   

5. Quais cores e propriedades visuais você escolheu e qual foi o resultado observado no navegador?

Escolhi as cores #00A19B, #2E7D32 e #D32F2F para destacar diferentes textos da página. Usei background-color padding para deixar separado os textos com um pouco de border 

6. Qual alteração ou correção foi necessária depois que você testou a página?

Foi necessário trocar as cores pelo código HEX por dificuldade de leitura
